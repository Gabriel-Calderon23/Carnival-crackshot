# Carnival Crackshot

**Carnival Crackshot** es un videojuego arcade de disparos ambientado en una galería de tiro del viejo oeste. Con un estilo retro y caricaturesco, el jugador debe acertar a una serie de patos de goma en movimiento antes de cometer demasiados errores. ¡Cada ronda es más difícil que la anterior!

## Jugabilidad

- Dispará a los patos que se mueven horizontalmente sobre dos carriles.
- Cada ronda tiene **10 patos**. Si acertás **al menos 8**, pasás de ronda.
- Si fallás 3 veces en una ronda... ¡Game Over!
- La velocidad de los patos aumenta en cada ronda.
